## Known Limitations / 已知限制

- Mechanical evidence cannot prove unavailable production behavior; high-impact gaps require human verification.
- Codex still supplies project-specific reasoning for declared contradictions and Decisions; deterministic tooling validates and routes those claims but does not replace engineering judgment.
- Product commands and dependency installation are intentionally not executed during rescue inspection.
- Linear rescue output is a proposal only; actual duplicate checks and writes use the separate authorized Linear workflow.
- The free Linear workspace issue limit requires the attached v1.0 Project Document as the current equivalent requirement record.
- Public or team publication profiles may produce additional safety Review or Block findings.
