# Whitebox Discovery Index / 白盒发现索引

This directory contains the evidence-backed project model produced during Phase 0.5 and Phase 1.

本目录保存 Phase 0.5 和 Phase 1 产生的证据化项目模型。

Read `../WHITEBOX_PROTOCOL.md` before filling these reports.

填写前必须先读取 `../WHITEBOX_PROTOCOL.md`。

## Files / 文件

| File | Purpose | 用途 |
|---|---|---|
| `SCAN_EVIDENCE.json` | Deterministic path and manifest evidence generated by the scanner; created per target project | Scanner 生成的确定性路径与 manifest 证据；由目标项目生成 |
| `PROJECT_MAP.md` | Repository shape, components, entry points, runtime flows, and coverage | 仓库形态、组件、入口、运行流程和覆盖 |
| `DEPENDENCY_MAP.md` | Packages, runtimes, infrastructure, and external integrations | package、运行时、基础设施和外部集成 |
| `DOCUMENT_INVENTORY.md` | Documentation authority, freshness, conflicts, and gaps | 文档权威性、新鲜度、冲突和缺口 |
| `SETTINGS_AND_DATA_REGISTER.md` | Setting names, schemas, stores, lifecycle, and unknowns without secret values | 不含 secret 值的设置名、schema、存储、生命周期和未知项 |
| `LOGIC_BOUNDARY_AUDIT.md` | Invariants, state flows, trust boundaries, contradictions, and design gaps | 不变式、状态流、信任边界、矛盾和设计缺口 |
| `WHITEBOX_IMPORT_REPORT.md` | Human review and Linear handoff summary | 人工 review 和 Linear 交接摘要 |

## Scanner / 扫描器

Dry run, no writes:

```bash
python3 project-os/tools/whitebox_scan.py --root .
```

Write deterministic evidence under this directory:

```bash
python3 project-os/tools/whitebox_scan.py --root . --write
```

Check whether existing evidence is current:

```bash
python3 project-os/tools/whitebox_scan.py --root . --check
```

The scanner output is evidence input, not a completed whitebox report. Codex must still inspect important code paths, compare sources, record contradictions, and ask humans about high-impact unknowns.

Scanner 输出是证据输入，不是已完成的白盒报告。Codex 仍必须检查重要代码路径、比较来源、记录矛盾，并就高影响未知项询问人类。

## Completion / 完成

Replace template rows with project evidence. Keep unresolved rows instead of deleting them. Empty tables, missing coverage notes, or unsupported claims mean discovery is still incomplete.

用项目证据替换模板行。未解项应保留，不要删除。空表、缺失覆盖说明或无证据结论都表示 discovery 尚未完成。
